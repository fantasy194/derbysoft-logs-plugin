# Configure log access

Use the plugin's Structured Settings in its details page as the primary configuration surface. `open_log_settings` opens the MCP App fallback, which uses the same settings. Read `../../README.md` for installation and UI details. Credentials belong to the user and are never included in the shared plugin.

1. Identify the environment to configure and its services. Ask when the environment or desired default is unclear. Create a named environment and manually enter its connection settings. Never infer identity from an endpoint, copy another environment's credentials, or import existing profiles.
2. In settings, create a named environment such as `uat` or `prod`; use this one name for both display and query routing, then set service endpoints, OpenSearch username and default index, optional StreamLog default client, and Loki options as supplied. Each environment has its own `streamlog.default_client`; it is public configuration, not a credential or a global service default. Set the global **默认环境** only when the user wants it. A default is a pointer to a named environment, not another environment.
3. Use the environment's **配置凭证** action to open that environment in the settings page, where the user enters service addresses and credentials together and saves them. An empty credential field keeps the existing credential unless its endpoint, username, or authentication mode changed; the user can enter a replacement in the same save. Do not ask the user to paste secrets into chat or put plaintext secrets in tool arguments, query files, command-line arguments, profile JSON or logs. The page encrypts entered credentials for the local settings service, which stores them in the OS credential store without a plaintext fallback. Never reuse another service's or environment's credentials.
4. Use that environment's **测试连接** action and read its result dialog. For a configured OpenSearch default index, the connection test runs a read-only `match_none` search with `size=0`; no business documents are returned. A root or metadata 403 does not establish that index searches are forbidden, and zero shards, timeout, or failed shards do not establish that an index is accessible. Verify StreamLog using a known client, token and time range; verify Loki with label discovery and a bounded application query. Report which checks actually succeeded and what remains unverified.
5. A missing default OpenSearch index needs an explicit index or a value configured for the selected environment. Do not infer an index from a topic name or retry with `*` after an error. Query results identify the selected environment and index scope.
6. For StreamLog, an explicit tool `client` overrides the selected environment's default client. Correlation also accepts an explicitly observed record `client` before the environment fallback. If no applicable value exists, ask for the client or configure it in that environment; never infer it from supplier, channel, topic or index. Reuse the actual returned client for subsequent pages and details in the same investigation. Changing only this default does not replace credentials; clearing it restores the requirement for an explicit client.

Configuration is read at the next MCP call. Updating the installed plugin itself may require refreshing the plugin connection or starting a new conversation. If native settings do not appear, use `open_log_settings`; if the tools are unavailable, diagnose the installation rather than creating custom MCP clients or query scripts. Plain service environment variables cannot silently override an explicitly selected saved environment. Explain any effective `DERBYSOFT_LOGS_PROFILE` override.

For an explicit request to remove an environment, direct the user to its **删除环境** action and the name-confirmation dialog. Deleting the default clears the default selection; it never selects another environment. Do not delete an environment as a repair or setup shortcut.

Never disable TLS, change VPN settings, publish business logs, or write to a log cluster as a setup workaround. Explain errors without echoing credentials.
